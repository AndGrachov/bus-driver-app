# Bus Driver App

Demo mobile app for bus and coach drivers: today's and upcoming assignments, trip details, live trip status and dispatcher changes.

Built with Expo (React Native) and TypeScript. Runs on iOS, Android and the web.

## Getting started

```bash
npm install
npx expo start      # press i for the iOS simulator, w for the web
```

## Scripts

| Command | What it does |
|---|---|
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript check |
| `npm test` | Unit tests (Jest) |
